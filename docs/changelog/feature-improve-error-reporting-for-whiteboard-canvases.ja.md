# ホワイトボードキャンバスの明確な読み込みエラー

**機能ブランチ:** feature-improve-error-reporting-for-whiteboard-canvases

## キャンバスの読み込み失敗を明確に報告

キャンバスのセッションや描画の失敗時に、ブラウザーに具体的なメッセージを表示し、開発者コンソールにキャンバス識別子と読み込み段階を記録します。サーバー側のスナップショット読み込み失敗は、安全で明確な API エラーを返し、構造化された診断メタデータをサーバーログに記録します。
