# Teilnahme an aktiven Arbeitsflächen erweitern

**Feature-Zweig:** feature-add-user-support-to-active-canvases

## Neu eingeladene Benutzer zu bestehenden Arbeitsflächen hinzufügen

Dauerhafte Arbeitsflächen bieten nun eine optionale Provider-Capability, mit der Meeting-Integrationen die Teilnehmerliste einer aktiven Arbeitsfläche erweitern können. Nur der Eigentümer der Arbeitsfläche darf die validierten Kontoprofile berechtigen, und jeder neue Editor erhält Zugriff auf die aktuell gespeicherte Szene, ohne bestehende Teilnehmer zu ersetzen.
