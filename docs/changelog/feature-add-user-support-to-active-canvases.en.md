# Expand active canvas participation

**Feature Branch:** feature-add-user-support-to-active-canvases

## Add newly invited users to existing canvases

Persistent canvases now expose an optional provider capability that lets meeting integrations extend an active canvas participant list. Only the canvas owner may grant the validated account profiles, and every new editor receives access to the current saved scene without replacing existing participants.
