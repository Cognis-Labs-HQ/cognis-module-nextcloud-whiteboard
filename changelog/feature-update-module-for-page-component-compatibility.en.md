# Update module for page component compatibility

**Feature Branch:** feature-update-module-for-page-component-compatibility

## Expose the whiteboard canvas as a component page

The whiteboard canvas route now declares localized component metadata and supports overlay, fullscreen, and picture-in-picture presentation modes.

## Use stable dotted route identifiers

Whiteboard page routes now use dot-separated identifiers so other Cognis components can request the canvas through the page component contract.
