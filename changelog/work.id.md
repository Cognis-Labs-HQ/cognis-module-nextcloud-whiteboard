# Galat pemuatan kanvas papan tulis yang jelas

**Cabang Fitur:** work

## Laporkan kegagalan pemuatan kanvas dengan jelas

Kegagalan sesi dan perenderan kanvas kini menampilkan pesan khusus di peramban serta menyertakan pengenal kanvas dan tahap pemuatan di konsol pengembang. Kegagalan snapshot pada sisi server mengembalikan galat API yang aman dan jelas serta menulis metadata diagnostik terstruktur ke log server.
