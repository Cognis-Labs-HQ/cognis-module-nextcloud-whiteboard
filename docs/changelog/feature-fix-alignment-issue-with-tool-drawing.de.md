# Präzise Platzierung beim Zeichnen

**Feature-Zweig:** feature-fix-alignment-issue-with-tool-drawing

## Erstellte Objekte am Zeiger ausrichten

Beim Beginn des Zeichnens wird die Zeichenfläche durch das Fokussieren nicht mehr verschoben. Die anfängliche Zeichenposition wird vor dem Fokuswechsel erfasst, sodass Zeiger und neues Objekt an der anvisierten Stelle bleiben.
