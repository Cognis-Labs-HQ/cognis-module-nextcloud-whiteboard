# ホワイトボードのテキストサイズを統一

**機能ブランチ:** feature-fix-text-rendering-size-consistency

## テキストがテキストボックスのサイズに追従

入力中、テキストボックスがレンダリングされたテキストの正確な寸法に合わせて拡大・縮小するようになりました。テキストボックスのサイズを手動で変更した後も、以降のサイズ変更に合わせてフォントが拡大・縮小されます。
