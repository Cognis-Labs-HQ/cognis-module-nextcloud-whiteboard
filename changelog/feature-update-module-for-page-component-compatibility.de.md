# Modul für Seitenkomponenten-Kompatibilität aktualisieren

## Whiteboard-Zeichenfläche als Seitenkomponente bereitstellen

Die Route der Whiteboard-Zeichenfläche deklariert nun lokalisierte Komponentenmetadaten und unterstützt die Darstellungsmodi Überlagerung, Vollbild und Bild-in-Bild.

## Stabile punktgetrennte Routenkennungen verwenden

Whiteboard-Seitenrouten verwenden nun punktgetrennte Kennungen, damit andere Cognis-Komponenten die Zeichenfläche über den Seitenkomponentenvertrag anfordern können.
