# キャンバスメンバーシップのオーケストレーションを追加

**機能ブランチ:** work

## 直接的なメンバーシップ変更を提供

Jitsi Meet などのオーケストレーターは、正規の実行者アカウント ID とユーザーアカウント ID を指定し、CTX capability `whiteboard:membership` を介してキャンバス参加者を追加または削除できるようになりました。この変更を実行できるのはキャンバス所有者だけで、所有者自身のアクセスは削除できません。
