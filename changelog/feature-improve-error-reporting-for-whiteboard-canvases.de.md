# Eindeutige Ladefehler für Whiteboard-Zeichenflächen

**Feature-Zweig:** feature-improve-error-reporting-for-whiteboard-canvases

## Ladefehler der Zeichenfläche klar melden

Fehler beim Laden der Sitzung oder beim Darstellen werden jetzt mit einer eindeutigen Meldung im Browser angezeigt. Die Entwicklerkonsole enthält außerdem die Kennung der Zeichenfläche und die Ladephase. Serverseitige Fehler beim Laden eines Schnappschusses liefern einen sicheren, eindeutigen API-Fehler und schreiben strukturierte Diagnoseangaben in das Serverprotokoll.
