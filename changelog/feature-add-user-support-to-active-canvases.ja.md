# アクティブなキャンバスへの参加を拡張

**機能ブランチ:** feature-add-user-support-to-active-canvases

## 新しく招待されたユーザーを既存のキャンバスに追加

永続キャンバスに任意の Provider Capability を追加し、ミーティング連携からアクティブなキャンバスの参加者一覧を拡張できるようにしました。検証済みのアカウントプロフィールを許可できるのはキャンバス所有者だけで、新しい編集者は既存の参加者を置き換えることなく、現在保存されているシーンへアクセスできます。
