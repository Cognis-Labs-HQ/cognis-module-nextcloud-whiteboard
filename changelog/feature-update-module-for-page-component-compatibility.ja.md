# ページコンポーネント互換性に対応するようモジュールを更新

**機能ブランチ:** feature-update-module-for-page-component-compatibility

## ホワイトボードキャンバスをページコンポーネントとして公開

ホワイトボードキャンバスのルートにローカライズされたコンポーネントメタデータを宣言し、オーバーレイ、フルスクリーン、ピクチャーインピクチャーの各表示モードに対応しました。

## 安定したドット区切りのルート識別子を使用

ホワイトボードのページルートにドット区切りの識別子を使用し、他の Cognis コンポーネントがページコンポーネント契約を通じてキャンバスを要求できるようにしました。
