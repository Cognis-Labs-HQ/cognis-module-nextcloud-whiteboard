# Precise drawing placement

**Feature Branch:** feature-fix-alignment-issue-with-tool-drawing

## Align created objects with the pointer

Focusing the canvas no longer scrolls it when drawing begins. The initial drawing position is captured before focus changes, so the pointer and new object remain at the location the user targeted.
