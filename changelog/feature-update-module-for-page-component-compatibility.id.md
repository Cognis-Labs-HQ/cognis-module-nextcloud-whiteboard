# Perbarui modul untuk kompatibilitas komponen halaman

**Cabang Fitur:** feature-update-module-for-page-component-compatibility

## Sediakan kanvas papan tulis sebagai komponen halaman

Rute kanvas papan tulis kini mendeklarasikan metadata komponen yang dilokalkan serta mendukung mode tampilan hamparan, layar penuh, dan gambar-dalam-gambar.

## Gunakan pengenal rute bertitik yang stabil

Rute halaman papan tulis kini menggunakan pengenal yang dipisahkan titik agar komponen Cognis lain dapat meminta kanvas melalui kontrak komponen halaman.
